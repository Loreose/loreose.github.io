# ox_inventory

A complete, high-performance inventory system for FiveM, implementing items, weapons, shops, and advanced crafting mechanics without any strict framework dependency.

---

## 📚 Resources & Downloads

- **Official Documentation:** [https://loreose.github.io/docs](https://loreose.github.io/docs)
- **Original Source Download:** [ox_inventory Latest Release](https://github.com/overextended/ox_inventory/releases/latest/download/ox_inventory.zip)

## 📌 Custom Features Overview

This build includes enhanced systems designed for advanced roleplay servers:

1. **Equipment & Clothing Engine:** Wearable inventory slots that dynamically sync with GTA V ped components and props.
2. **Portable Handcrafting:** On-the-go crafting without requiring physical world stations.
3. **Location-Based Workbenches:** Advanced crafting stations supporting polyzones and tool durability wear.
4. **Clothing Slash Commands & Real-Time Sync:** Automatic command registration and ped scanning.

## 📌 1. Newly Added & Available Exports

### 🧥 Clothing & Equipment Exports

#### `GetEquipments` (Client & Server)

Retrieves all currently equipped items for the local player or a target player.

```lua
-- Client-side:
local equipments = exports.ox_inventory:GetEquipments()
-- Returns: { ["1"] = { name = "jacket", metadata = { drawable = 10, texture = 0 } }, ... }

-- Server-side (by Player Server ID):
local targetSource = 1
local equipments = exports.ox_inventory:GetEquipments(targetSource)
```

#### `ToggleClothing` (Client)

Toggles (equips or unequips) a specific clothing item with its assigned animation.

```lua
-- Example: Toggle jacket on/off
exports.ox_inventory:ToggleClothing('jacket')

-- Example: Toggle mask on/off
exports.ox_inventory:ToggleClothing('mask')
```

#### `SyncClothingFromPed` (Client)

Scans the ped's currently worn clothing and synchronizes it with the inventory equipment slots (useful after barber shops, plastic surgeons, or clothing stores).

```lua
-- force = true (Forces re-sync even if hash hasn't changed)
exports.ox_inventory:SyncClothingFromPed(true)
```

#### `ApplyEquipments` (Client)

Applies the items currently saved in the equipment slots directly onto the ped model.

```lua
exports.ox_inventory:ApplyEquipments()
```

---

### 🔨 Handcrafting Export

#### `openHandcrafting` (Client)

Opens the portable handcrafting panel directly, without requiring any workbench or nearby station.

```lua
exports.ox_inventory:openHandcrafting()
```

## 📦 2. How to Add New Items

New items are defined in `data/items.lua`.

### 📝 Example Item Definitions

```lua
['sticks'] = {
    label = 'Sticks',             -- Display name in inventory
    weight = 50,                  -- Weight in grams
    stack = true,                 -- Can this item be stacked?
    close = false,                -- Should inventory close when used?
    gridWidth = 1,                -- Grid width in inventory slots (1-5)
    gridHeight = 1,               -- Grid height in inventory slots (1-5)
    description = 'Dry wooden sticks gathered from trees.',
},

['campfire'] = {
    label = 'Campfire',
    weight = 1000,
    stack = false,
    close = true,
    gridWidth = 2,
    gridHeight = 2,
    description = 'A portable campfire used for warmth and cooking.',
    client = {
        anim = { dict = 'amb@world_human_gardener_plant@male@base', clip = 'base' },
        usetime = 3000,
    }
},
```

### 🖼️ Item Images

Place item icons in lowercase PNG format in the following directory:

- **Path:** `ox_inventory/web/images/<item_name>.png`
- *Examples:* `ox_inventory/web/images/sticks.png`, `ox_inventory/web/images/campfire.png`

## 🔨 3. How to Configure Handcrafting

Handcrafting recipes are defined in `data/handcrafting.lua`. Players can craft these items on the go using materials in their inventory without any workbench.

### 📝 Example Handcrafting Recipe

```lua
return {
    name = 'handcrafting',
    items = {
        {
            name = 'campfire',            -- Item name (must exist in items.lua)
            ingredients = {
                sticks = 5,               -- Required items and quantities
            },
            duration = 5000,              -- Crafting duration in milliseconds (5000 = 5s)
            count = 1,                    -- Amount produced
        },
        {
            name = 'lockpick',
            ingredients = {
                scrapmetal = 3,
            },
            duration = 4000,
            count = 1,
        },
    }
}
```

## 🏭 4. How to Configure Workbench Crafting

Location-based workbench crafting tables are defined in `data/crafting.lua`.

### 📝 Example Crafting Bench Definition

```lua
return {
    {
        name = 'workbench_mechanic',      -- Unique workbench identifier
        label = 'Mechanic Workbench',     -- Display title
        items = {
            {
                name = 'WEAPON_KNIFE',
                ingredients = {
                    scrapmetal = 5,
                    sticks = 3,
                    WEAPON_HAMMER = 0.05  -- Decimal value (0.05) degrades durability by 5% instead of consuming the tool
                },
                duration = 5000,
                count = 1,
            },
            {
                name = 'lockpick',
                ingredients = {
                    scrapmetal = 4,
                },
                duration = 3000,
                count = 2,
            }
        },
        points = {
            -- World interaction coordinates:
            vec3(-1147.08, -2002.66, 13.18),
        },
        zones = {
            -- Optional target/polyzone box:
            {
                coords = vec3(-1146.2, -2002.05, 13.2),
                size = vec3(2.0, 1.0, 1.0),
                rotation = 45.0,
            }
        }
    }
}
```

## 🎽 5. How to Add New Clothing Pieces (Decals, Bracelet, Watch, etc.)

GTA V ped models manage clothing and accessories using **Component** IDs and **Prop** IDs.

### 📋 GTA V Ped ID Reference Table

| Type | Classification | ID | Description |
| :--- | :--- | :--- | :--- |
| **Mask** | Component | `1` | Face masks & balaclavas |
| **Torso / Hands** | Component | `3` | Gloves, arms, upper body base |
| **Pants** | Component | `4` | Pants, trousers, jeans |
| **Bag** | Component | `5` | Backpacks & parachutes |
| **Shoes** | Component | `6` | Shoes, boots, sneakers |
| **Necklace** | Component | `7` | Chains, ties, necklaces, scarves |
| **Shirt** | Component | `8` | Undershirts, t-shirts |
| **Vest** | Component | `9` | Body armor, tactical vests |
| **Decals / Badges** | Component | `10` | Badges, patches, rank insignias |
| **Jacket** | Component | `11` | Jackets, coats, hoodies, tops |
| **Hat / Helmet** | Prop | `0` | Hats, caps, helmets |
| **Glasses** | Prop | `1` | Sunglasses, spectacles |
| **Earrings** | Prop | `2` | Ear accessories |
| **Watch** | Prop | `6` | Wrist watches |
| **Bracelet** | Prop | `7` | Wrist bracelets |

### 🛠️ Step-by-Step: Adding New Clothing Items

#### Step 1: Add Definitions to `data/clothing.lua`

```lua
-- Adding Watch (Prop 6):
['watch'] = {
    label = 'Watch',
    weight = 100,
    stack = false,
    close = true,
    clothing = true,
    prop = 6,              -- Prop ID: 6 (Watch)
    gridWidth = 1,
    gridHeight = 1,
    client = {
        anim = { dict = 'clothingspecs', clip = 'take_off' },
        usetime = 1000
    }
},

-- Adding Bracelet (Prop 7):
['bracelet'] = {
    label = 'Bracelet',
    weight = 50,
    stack = false,
    close = true,
    clothing = true,
    prop = 7,              -- Prop ID: 7 (Bracelet)
    gridWidth = 1,
    gridHeight = 1,
    client = {
        anim = { dict = 'clothingspecs', clip = 'take_off' },
        usetime = 1000
    }
},

-- Adding Badge / Decal (Component 10):
['badge'] = {
    label = 'Badge',
    weight = 50,
    stack = false,
    close = true,
    clothing = true,
    component = 10,        -- Component ID: 10 (Decals)
    gridWidth = 1,
    gridHeight = 1,
    client = {
        anim = { dict = 'clothingtie', clip = 'try_tie_positive_a' },
        usetime = 1200
    }
},
```

#### Step 2: Automatic Commands & Sync

- Any item added to `data/clothing.lua` automatically registers an associated slash command with the exact item name (e.g., `/watch`, `/bracelet`, `/badge`).
- The ped scanner dynamically tracks these components/props and updates the player's equipment slots accordingly.

#### Step 3: Add Item Icons

Add corresponding PNG icons in `ox_inventory/web/images/`:

- `ox_inventory/web/images/watch.png`
- `ox_inventory/web/images/bracelet.png`
- `ox_inventory/web/images/badge.png`
