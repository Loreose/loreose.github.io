# Clothing & Accessories Configuration

`ox_inventory` features a dedicated clothing and equipment subsystem that binds inventory slots directly to GTA V ped drawable components and props.

---

## GTA V Ped ID Reference Table

GTA V ped models separate wearable assets into **Components** (body parts and clothing meshes) and **Props** (attached accessories like hats, glasses, and wrist items).

| Type | Classification | ID | Description |
| :--- | :--- | :--- | :--- |
| **Mask** | Component | `1` | Face masks, bandanas, and balaclavas |
| **Torso / Hands** | Component | `3` | Gloves, arms, and upper body skin base |
| **Pants** | Component | `4` | Pants, trousers, and jeans |
| **Bag** | Component | `5` | Backpacks, duffel bags, and parachutes |
| **Shoes** | Component | `6` | Shoes, boots, and sneakers |
| **Necklace** | Component | `7` | Chains, ties, scarves, and necklaces |
| **Shirt** | Component | `8` | Undershirts and inner t-shirts |
| **Vest** | Component | `9` | Body armor and tactical vests |
| **Decals / Badges** | Component | `10` | Badges, police ranks, and shoulder patches |
| **Jacket** | Component | `11` | Jackets, hoodies, coats, and outer tops |
| **Hat / Helmet** | Prop | `0` | Hats, caps, beanies, and helmets |
| **Glasses** | Prop | `1` | Sunglasses and spectacles |
| **Earrings** | Prop | `2` | Ear accessories and piercings |
| **Watch** | Prop | `6` | Wrist watches |
| **Bracelet** | Prop | `7` | Wrist bracelets and bands |

## 🛠️ Step-by-Step: Adding New Clothing Items

Follow these steps to register new wearable items (such as watches, bracelets, and police badges):

### Step 1: Add Definitions to `data/clothing.lua`

Open [`ox_inventory/data/clothing.lua`](#) and register your items using either the `component` property or the `prop` property matching the table above:

```lua
-- data/clothing.lua

-- Adding Watch (Prop ID 6):
['watch'] = {
    label = 'Watch',
    weight = 100,
    stack = false,
    close = true,
    clothing = true,
    prop = 6,              -- Prop ID: 6 (Watch)
    gridWidth = 1,
    gridHeight = 1,
    client = {
        anim = { dict = 'clothingspecs', clip = 'take_off' },
        usetime = 1000
    }
},

-- Adding Bracelet (Prop ID 7):
['bracelet'] = {
    label = 'Bracelet',
    weight = 50,
    stack = false,
    close = true,
    clothing = true,
    prop = 7,              -- Prop ID: 7 (Bracelet)
    gridWidth = 1,
    gridHeight = 1,
    client = {
        anim = { dict = 'clothingspecs', clip = 'take_off' },
        usetime = 1000
    }
},

-- Adding Badge / Decal (Component ID 10):
['badge'] = {
    label = 'Badge',
    weight = 50,
    stack = false,
    close = true,
    clothing = true,
    component = 10,        -- Component ID: 10 (Decals / Badges)
    gridWidth = 1,
    gridHeight = 1,
    client = {
        anim = { dict = 'clothingtie', clip = 'try_tie_positive_a' },
        usetime = 1200
    }
},
```

---

### Step 2: Automatic Commands & Ped Sync

- **Auto-Registered Slash Commands:** Any item defined in `data/clothing.lua` automatically creates a corresponding slash command matching the item key (e.g., `/watch`, `/bracelet`, `/badge`, `/jacket`, `/mask`). Players can run these commands or bind them to toggle the clothing piece on/off.
- **Ped Scanner Synchronization:** The internal ped scanner continuously monitors the character's active component and prop indices. When clothing is changed through barbershops, plastic surgery, or clothing stores, the system reflects those updates in the inventory equipment slots.

---

### Step 3: Add Item Icons

Place the icon PNG files in all lowercase into `ox_inventory/web/images/`:

- `ox_inventory/web/images/watch.png`
- `ox_inventory/web/images/bracelet.png`
- `ox_inventory/web/images/badge.png`
